# HoshiLedger 极简离线记账

HoshiLedger 是一款基于 Flutter 开发的极简、完全离线的记账应用。本项目致力于提供无广告、不依赖网络的基础记账体验，确保用户数据的完全隐私与安全。

## 设计目标

- **极简交互**：去除冗余，核心功能触手可及，单手即可完成快速记账。
- **隐私安全**：数据完全保存在设备本地，无任何云端同步或网络请求。
- **视觉愉悦**：采用现代简约的设计风格，响应式交互体验，支持丰富的图标自定义。

## 技术实现说明

1. **金额整数化存储**：
   数据库中所有的金额字段均以“分”为单位（整型）进行存储，从底层避免浮点数计算产生的精度丢失问题，确保财务数据绝对准确。

2. **物理级离线设计**：
   应用不声明任何网络权限，确保数据在物理层面无法离开设备，提供极致的隐私保障。

3. **全局响应式同步**：
   基于 `ValueNotifier` 构建了全局数据通知机制。当分类或账单发生变更时，应用内所有相关页面（账单、统计、设置）会自动触发实时刷新，无需重启或手动操作。

4. **动态分类与图标系统**：
   内置 30+ 细分领域图标，支持分类名称与图标的自由增删改查。系统会自动根据分类配置在全应用范围内同步展示对应的视觉标识。

## 核心功能模块

- **账单流水**：按月筛选并按天分组展示历史记录，支持点击记录进入编辑/删除，提供月度收支概览。
- **便捷记账**：通过账单页右上角 `+` 号快速调起记账弹窗。统一了新增与编辑的交互逻辑，支持备注模板快捷选择。
- **统计视图**：提供月度与年度的支出比例饼图及明细列表，直观展示资金流向。
- **数据管理**：支持全量数据导出为标准 CSV 文件，以及数据一键清空功能。
- **个性化设置**：提供紧凑型导航布局，支持多维度分类自定义。

## 运行项目

1. 确保已在本地配置好 [Flutter 开发环境](https://docs.flutter.dev/get-started/install)。
2. 连接 Android 或 iOS 测试设备，并开启开发者模式/USB调试。
3. 在项目根目录下执行以下命令：
   ```bash
   flutter run
   ```
